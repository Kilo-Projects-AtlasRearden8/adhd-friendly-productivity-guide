# Printable Worksheets

Print any worksheet below and fill it out by hand. No app, no account, no
tracking. Each worksheet opens in your browser and is formatted for printing
(use File → Print, or Ctrl+P / Cmd+P).

## Worksheets

- [Tiny Task Planner](../worksheets/tiny-task-planner.html) — break one task into
  steps small enough to start right now
- [Body-Doubling Session Log](../worksheets/body-doubling-session-log.html) —
  track who and what helps you focus
- [Energy Map](../worksheets/energy-map.html) — notice your energy patterns over
  a few days
- [Gentle Daily Routine](../worksheets/gentle-daily-routine.html) — a flexible
  routine that fits the energy you actually have

## Printing tips

- Open the worksheet in your browser
- Choose File → Print
- Set margins to "Minimum" or "None" if the worksheet is cut off
- Print in black and white to save ink
- Keep completed worksheets in a folder or binder — seeing what you have done
  is its own reward

There is no wrong way to fill these out. Blank is fine. Half-finished is fine.
Using the same worksheet three days in a row is fine.
